# Ollama (private, local)

Gives you: a model that runs on your own PC, so private work never leaves it. Slow on small GPUs, text only
(the Lead writes the files it suggests).

1. Install from ollama.com, then pull a model: `ollama pull gemma4:12b` (8 GB VRAM: works but slow).
2. Use it with `-Local` (and `-LocalModel <name>` for another model).
